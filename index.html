Option 1 reads the Excel straight from a folder on your computer (for example where your report is saved) and refreshes when the file changes. The browser asks for permission once. Option 2 needs a web address, such as data/BO_Dashboard.xlsx on your Netlify site. A typed path like C:\Reports cannot be used by a web page – use Option 1 for that.

Publish to GitHub – update the dashboard for everyone

Choose the new Excel here. The dashboard checks it, shows it, and saves it into your GitHub project so every visitor gets it.

Create the token at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access select only this repository, and under Permissions → Contents choose Read and write. Use it only on your own computer – anyone with the token can change your repository.
